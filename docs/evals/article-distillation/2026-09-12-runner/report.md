# 独立评估运行器验收

日期：2026-09-12。

## 交付

评估能力迁至仓库 `evals/article-distillation/`。生产 skill 保留文章独立验收，仅以链接指向版本评估工具。固定案例、通用评分规则和案例评分要点与被测 skill 分离。

运行器支持 prepare、next、complete、report 和 run：准备完整版本/测试快照，调度中立任务，冻结首次产物，先盲读再交给新上下文核对原文，汇总原始评分。当前会话通过 subAgent 桥接真实运行；普通终端全自动运行需配置符合 stdin/stdout JSON 协议的 worker，本次未接入特定供应商 SDK。

## 工具自身验证

19 项标准库单元测试通过，无模型调用。覆盖：

- 阶段门槛、盲读前不提供原文与评分要点、评分阶段提供原始用户任务。
- 不允许重复使用生成/评审上下文，不允许覆盖已冻结首版。
- 冻结材料与评分规则防篡改，评估代码升级后拒绝用新逻辑处理旧运行。
- 原子复制及状态提交中断后的恢复，worker 失败后保留可恢复任务。
- 缺失产物、非法评分、缺少浏览器证据、路径越界和符号链接拒绝。
- 结构失败单列保存；候选赢票不能抵消维度退步；开发集与保留集分别汇总。
- 实际后端信息记录；已知模型不一致标为不可比；未知信息保持 null。
- 外部进程 worker 协议端到端测试。该项使用明确的测试替身，不是语义效果评估。

另一个未参与实现的 subAgent 只读审查，发现冻结中断恢复、评估代码固定、评审任务信息、后端报告四个问题。修复并增加相关测试后，原审查者定向复核确认四项关闭。Skill 格式、迁移引用和补丁格式检查通过。

## 真实 subAgent 端到端试跑

运行案例为 approval-workflow（开发集、规划范围），基线和候选各一次。运行器产生任务材料；协调者使用四个全新上下文分别生成两组产物、盲读、评分。所有产物均由运行器登记、冻结和校验，未接收外部修订反馈。

| 指标 | 基线 | 候选 |
| --- | --- | --- |
| 忠实性 | 3 | 3 |
| 论证保留 | 3 | 3 |
| 中文表达 | 3 | 3 |
| 阅读结构 | 3 | 3 |
| 图形语义、布局交互 | 未评估 | 未评估 |
| 阻断问题 | 0 | 0 |

盲评结论：tie。运行器判定 `no_demonstrated_improvement`，所选范围覆盖 1/1。没有证据表明该样本中候选更好；未运行其他四案、多次重复或实际 HTML 渲染。精确模型、推理参数及工具配置没有在后端元数据中暴露，因此 comparability 为 unknown；不把继承父代理设置当作完整实验证明。

## 证据

- A.md、B.md：原始匿名产物。
- reader.md：接触原文之前保存的复述。
- source.md：固定合成正文。
- blind-judgment.json：独立评分原件。
- judgments.json、summary.json：运行器实际整理和汇总结果。
- manifest.json：案例、揭盲映射及冻结材料哈希。
- baseline-skill.zip、candidate-skill.zip：实际被测版本。
- evaluation-tool.zip：实际运行的代码、案例及评分标准快照。

临时目录路径、上下文标识与原始调度回执不纳入此报告目录。时间记录含协调等待，不是纯模型推理耗时。文件读取隔离依赖代理遵守限制，不是操作系统安全边界；本次没有验证任何供应商的独立进程模型适配器。
