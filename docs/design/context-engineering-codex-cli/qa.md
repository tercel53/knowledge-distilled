# 视觉与交互验收：Codex CLI 上下文工程

## 本轮目标

把 Write、Select、Compress、Isolate 四类上下文操作做成可编辑的 HTML/CSS 图解，并确保文章主线、证据边界、自测和来源在 HTML、Markdown、metadata 中一致。

## 观察范围

- 桌面：1365 × 900。
- 手机：390 × 844。
- 状态：主阅读默认状态；自测答案默认折叠，并验证第一题展开/收起。
- 截图限制：浏览器接口可返回即时截图用于观察，但不能把截图字节保存到仓库路径，因此本目录没有持久化 PNG。以下视觉结论可由冻结版本重新打开复现，但不以不存在的截图宣称完整证据。

## 修正历史

1. 初版使用中央窗口与伪元素箭头。独立评估发现 Write / Select 方向相反、文字遮挡中心，移动端还隐藏方向标记。
2. 第二版改成四个独立微型信息流，在桌面和手机都显示端点与方向；但 Isolate 的斜箭头仍排成单行，可能被读成窗口 A → 窗口 B。
3. 最终版为 Isolate 建立共享源、分叉干线、横向分支和分别指向窗口 A/B 的两条连接；Round 03 评估确认几何歧义关闭。

同时修正：组合图明确标注为阅读归纳，移除暗示固定路径的新词，拆开提示工程/上下文工程/Harness 工程三层职责，并为 Markdown 四道自测补齐逐题原文链接。

## 已验证

- 桌面与手机均无页面横向溢出，卡片、文字和连接线无遮挡。
- Write：当前窗口 → 外部状态；Select：外部资料 → 当前窗口；Compress：较长内容 → 较短表示。
- Isolate：共享上下文通过一个明确分叉点进入窗口 A 与窗口 B，两支独立，没有 A → B 串联暗示。
- 390px 下四类信息流仍保留端点和方向，没有以响应式为由隐藏关系。
- 目录深链接可达，自测四题默认折叠、可独立展开，键盘焦点保持；控制台无 warning/error。
- 文章结构校验通过：18 个 ID、6 个目录标签、6 个 metadata outline 条目。

## 语义验收

- 默认标题、主图、图例和四类操作不是线性步骤，而是围绕有限窗口处理外存、读入、缩短与分界。
- 详细区补充 Codex 机制、组合、代价和证据强度，没有在答案区首次解释核心主线。
- 官方可核对的产品机制、作者的四策略映射、第三方效果数字与本笔记的证据评价保持区分。

## 残余限制

- 严格图解盲读仍为“未验证”：读者浏览器会在首遍截图前自动暴露整页可访问文本，三轮读者都如实记录了污染。因此不能把他们的正确复述称为只看主图所得的独立证据。
- 未取得禁用 JavaScript 后的实际浏览器截图；自测无脚本可用性由原生 `details` / `summary` 结构和脚本职责范围核对。
- 来源更新时间在不同抓取工具中分别显示 2026-09-09 与 2026-09-10。本地采用网页抓取到的 2026-09-09，并在独立评估中记录为来源动态差异。
