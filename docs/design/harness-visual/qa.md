# 图形优先的阅读展示验收

日期：2026-09-12

## 本轮依据
用户确认内容基本可用，要求减少阅读后自行组装关系的负担，改用图直观表达关系，文字辅助说明。沿用现有配色、字体、阅读顺序和章节索引。此次明确授权调整图示，不以历史 overview.png 为还原目标。

使用 Product Design 的上下文确认、现有界面截图与渲染检查方法；按照用户既有可编辑图要求，图解直接使用 HTML/CSS/SVG，不改为位图，不引入应用框架。图标复用仓库 Bootstrap Icons（许可证 assets/icons/LICENSE.bootstrap-icons）。

## 图形语义
- 总览：工程师建设环境，知识入口、规则检查、观察反馈共同支撑 Agent；虚线返回环境表示持续改进。
- 知识：分散知识经短入口供 Agent 使用。
- 规则：菱形表示检查，通过向前，违规则修正后重查。
- 反馈：实现、观察、发现偏差与修正构成循环；验证通过才交付，需要判断时交由人。
- 文字区保留原文摘要与阅读解释；图均为概念整理，不作为原文架构图或自主交付保证。

## 视觉与交互
- 桌面 1440 × 1100：检查总览、知识、规则和反馈图；节点层级明确，图与辅助说明并排，连线未穿过文字。
- 手机 390 × 844：总览保留三机制汇聚关系，实践改为图在前、说明在后，无页面横向溢出；检查规则图的分支与修正方向。
- 801 × 1000：断点附近无页面横向溢出，总览仍可读。
- 图中知识入口可点击跳转；手机规则节点 Enter 可跳转到对应实践；查看章节 06 自动展开原文章节。
- 浏览器未记录脚本错误；静态检查通过：ID 唯一、锚点、图形无障碍名称、图标文件和元数据对应；git diff --check 通过。
