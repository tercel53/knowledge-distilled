# 本轮要求与冻结范围

用户确认：仅有局部图、依靠读完长文才能理解全文，不符合图解优先的期望。图与标题、图注和必要短说明必须带领读者理解完整主线；长文用于深入解释和依据，不得补救核心连接。

本轮同步更新读者/评估者规则与页面；产物及角色哈希见 version.txt。验收分别判断内容准确完整、图解主线可理解、完整阅读顺畅。先冻结图解首遍记录，再读长文，不把第二遍理解追认为图解效果。无用户选定的位图参考。

原文：Dan Koe，2025-12-23，https://letters.thedankoe.com/p/how-to-fix-your-entire-life-in-1 ，正文 I–VII。已知读者背景采用读者角色默认值。独立角色不读取旧报告；旧结论保留，但不能证明本轮更严格要求已满足。
