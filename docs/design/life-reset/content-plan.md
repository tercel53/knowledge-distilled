# 新版论证骨架

## 五问

- 问题：明明想改变，为何又回到旧行为？
- 结论：作者主张辨认行为的隐性目的，重新审视自我认同，以一天练习定向，再用行动反馈持续调整。
- 机制：行为可能保护熟悉的自我认识；反思将冲突和代价显现，白天观察检验自述，晚上落实行动，后续结果用于修正。不是仅靠更强自律或更换自我描述。
- 证据：个人经验、例子、发展框架与控制论类比；没有整套练习的对照效果研究。辅助写作情境是笔记解释，不是原文实证。
- 边界与代价：原文承认个体阶段差异、机会和行动能力；一天时间与可能不舒服的反思。不能从行为诊断动机或承诺人生改变，现实限制不能归为意愿不足（阅读判断）。

## 连续解释

为解释改变为何反复失败，作者把注意力从表面愿望转到行为保护的目标及自我认同。若行动威胁旧定义，人可能选择安全而偏离愿望；因此要先看清这种冲突。一天练习用反思明确方向，用观察核对实际选择，再把发现转成下一步。反思没有替代行动：行动结果通过观察、比较和调整，才与未来方向持续连接。依据主要是作者论述与经验，不能保证每个人都有效。
