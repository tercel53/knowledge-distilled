## 本轮依据

- 核心结论保留；机制使用障碍 → 工程机制 → Agent 能力的三行图。

- 人的职责、实验条件、持续维护与长期未知放在边界部分。
- 11 个原章节及主题映射默认折叠；点击章节链接或加载章节 hash 时自动展开。
- 浏览器验证：1440 × 1100 桌面、390 × 844 手机均无页面横向溢出。
- 人工查看桌面和手机机制截图：桌面横向因果、手机纵向因果，箭头未覆盖文字。

- HTML IDs 唯一，内部锚点完整，元数据 11 个章节与页面对应；git diff --check 通过。
